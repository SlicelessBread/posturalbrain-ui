# posturalbrain-ui

Design system POSTURALBRAIN: variabili, stile e componenti condivisi dalle app.

- `design-system/project/` contiene i file pubblicati nella pagina Design System (variabili, componenti con anteprima, guida).
- `scripts/tokens-css.mjs` genera il foglio delle variabili da `design-system/project/tokens.json`.

## Comandi

```bash
npm test               # prove sugli script e sui file del design system
npm run tokens:css     # stampa il CSS delle variabili
```
