La scelta da elenco fa scegliere una voce tra molte già note.

**Quando usarla.** Quando le voci sono più di tre o hanno nomi lunghi: il collaboratore, il numero di rate. Sul telefono apre il selettore del sistema, comodo da usare con il pollice.

**Quando no.** Con due o tre voci corte usa la scelta a segmenti, che mostra tutte le opzioni senza un tocco in più. Se le voci sono moltissime (i pazienti), usa una ricerca.

**Cosa fornisce chi lo usa.**
- Un `label` `pb-field` con la sua etichetta.
- Un contenitore `pb-select` con dentro il `select` (classe `pb-input`) e l'icona della freccia.
- Una voce già selezionata quando esiste una scelta sensata; altrimenti una prima voce «Scegli…» non valida.
