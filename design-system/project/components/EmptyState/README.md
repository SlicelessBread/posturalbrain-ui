Lo stato vuoto spiega perché un elenco non ha ancora nulla e cosa fare per riempirlo.

**Quando usarlo.** Al posto di una lista o di una griglia senza voci: nessun paziente, nessun video assegnato, nessun post programmato, nessun risultato di ricerca.

**Quando no.** Mentre i dati stanno arrivando usa le sagome di attesa: lo stato vuoto compare solo quando si sa che non c'è niente. Per un errore di caricamento usa una fascia di errore.

**Cosa fornisce chi lo usa.**
- Un'icona a 32 px che richiama il tipo di contenuto mancante.
- Un titolo che dice cosa manca («Ancora nessun paziente»), senza scuse e senza punti esclamativi.
- Una frase che dice cosa succede aggiungendo il primo elemento.
- Il pulsante principale con l'azione, se la persona può fare qualcosa. Per una ricerca senza risultati, nessun pulsante: basta «Nessun paziente con questo nome».
