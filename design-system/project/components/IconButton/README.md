Il pulsante a icona è un'azione che si riconosce senza parole: chiudere, tornare indietro, aggiungere, aprire le notifiche.

**Quando usarlo.** Nelle barre e nelle intestazioni, dove lo spazio è poco. La variante principale (`pb-icon-btn--primary`) è l'azione di aggiunta di una lista e sta in alto a destra, una sola per pagina. La variante discreta (`pb-icon-btn--ghost`) serve per chiudere e tornare indietro.

**Quando no.** Se l'icona non è universale, usa un pulsante con il testo. Mai due pulsanti a icona principali nella stessa schermata.

**Cosa fornisce chi lo usa.**
- L'icona, a 24 px.
- `aria-label` con l'azione in parole («Aggiungi paziente»): è obbligatorio.
- Un `pb-dot` dentro il pulsante quando c'è qualcosa di non letto.

Il pulsante è un cerchio di 44 px: non rimpicciolirlo.
