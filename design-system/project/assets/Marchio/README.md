# Marchio

L'icona attuale dell'app, copiata da POSTURALBRAIN così com'è: una colonna vertebrale stilizzata su fondo blu sfumato.

- `icon.svg`: versione vettoriale, a colori propri. Si usa come icona dell'app e nella schermata di accesso. Non ricolorarla e non ritagliarla.
- `icon-512.png`: la stessa icona a 512 px per il telefono (icona sulla schermata principale).

È provvisoria: le grafiche dello studio cambieranno e questa cartella verrà sostituita. Non esiste ancora un logo con il nome: dove serve il nome, si scrive in `text-display` senza disegnarlo.
