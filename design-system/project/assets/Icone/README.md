# Icone

Icone a tratto della raccolta aperta Lucide (licenza ISC), copiate senza modifiche: griglia di 24 px, tratto di 2 px, estremità arrotondate.

Nei file il tratto è `currentColor`: dentro una pagina vanno incorporate come SVG nel codice, con classe `pb-icon`, così prendono il colore del testo che le contiene. Mostrate come immagine restano nere.

Misure: 24 px di norma, 18 px (`pb-icon--sm`) dentro etichette ed eventi, 32 px (`pb-icon--lg`) negli stati vuoti. Per aggiungerne una si prende dalla stessa raccolta, con lo stesso nome.
